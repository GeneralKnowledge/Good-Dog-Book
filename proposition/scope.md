# Scope and boundaries

**Status:** Living document (Stage B). **Author gate G1.**

## Feasibility in one volume

**Assessment:** The practical promise in `proposition.md` is achievable in **one book** (~70–90k words) if specialist clinical topics stay on **referral paths** rather than full treatment manuals.

## Primary audience (recommended)

Ordinary UK-oriented dog owners who want a **coherent method** for everyday life — not competitors, not professional trainers certifying others.

Secondary readers (experienced owners, new puppy guardians, rescue adopters) are served by **differentiated sections**, not separate books in this project phase.

## In scope

| Area | Depth |
| --- | --- |
| Learning theory (owner-facing) | Core chapters |
| Teaching loop, cues, rewards, timing, criteria | Core |
| Session design, generalisation, troubleshooting | Core |
| Engagement, name, sit/down/settle, mat/rest | Core |
| Recall foundations and management | Core + qualified review for distraction/off-lead |
| Lead walking foundations | Core — **method must pass qualified review before draft** |
| Doors, greetings (management-first), gentle handling | Core with qualified review on social protocols |
| Body language and stress (uncertainty-aware) | Core |
| Puppies (toilet, mouthing, gentle exposure principles) | Dedicated section |
| Adolescent regression (brief) | One chapter section |
| Rescue settling (management, expectations) | One chapter section |
| When to use vet / qualified trainer / behaviourist | Core closing part |
| British English; UK law/equipment basics at high level | One section — verify claims at draft time |

## Out of scope (boundary only or bibliography)

| Topic | Book treatment |
| --- | --- |
| Clinical aggression/reactivity treatment plans | Referral + what owners can do meanwhile (management) |
| Separation-related distress as DIY cure | Prevention tips only; clinical cases → professional |
| Competition obedience, sport, working dog specialisms | Not covered |
| Breed-by-breed encyclopaedia | Not covered |
| Medication, diagnosis, veterinary behaviour medicine | Vet-only; book points to vet |
| Multi-dog household protocols | Flagged gap in DogResearch; brief mention only until researched |
| Guaranteed outcomes (“fixed in 30 days”) | Prohibited |

## Training the Human / owner mantra

The subtitle frame and repeatable mantra (“Make it easier — then ask again.”) teach **owner habit change**. They are not clinical advice, guarantees, or a substitute for vet or behaviourist assessment.

## Good Dog app content

- **Do not** structure the book as ~28 exercise chapters.  
- Exercises may inspire **sidebars** or **practice labs** with explicit adaptation notes.  
- Material with audit status “substantial revision” or “qualified review” is **not book-ready** until resolved (see `research/good-dog-gap-reconciliation.md`).

## Companion product (decision)

**Recommendation:** Book stands alone; optional short appendix or back-cover note referencing Good Dog as a practice companion. **Author to confirm** before publication copy.
