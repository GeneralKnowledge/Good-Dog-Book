# ch04 — The teaching loop

## Prerequisites (reading order)
ch01–ch03 (read #4).

## Unique contribution
Repeatable **teaching loop**: **setup → cue → behaviour → mark/reward → release → reset**; install owner mantra **“Make it easier — then ask again.”**; introduce **five checks** when the loop stalls (full table in ch14).

## Practical outcome
Reader can teach a simple behaviour (e.g. sit or hand target) using the loop without drilling past enjoyment.

## Sections

Each section **must** use **Train yourself** / **Train the dog** with **Know / Do / Don't** ([`dual-track-pattern.md`](../../writing/dual-track-pattern.md)).

1. The loop diagram in prose — self: timing, one cue, stop rules · dog: behaviour → mark → pay association  
2. Splitting criteria — self: one criterion per session · dog: what earns the mark today  
3. When nothing happens — self: five checks / mantra · dog: easier rep, not louder cue
