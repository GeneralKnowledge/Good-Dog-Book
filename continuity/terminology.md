# Terminology register

**Living document.** Align manuscript and glossary with these choices unless a brief explicitly overrides.

| Term | Use | Avoid |
| --- | --- | --- |
| Lead | UK default | Leash (unless quoting US source) |
| Harness / collar | Neutral equipment terms | Choke, prong, shock (except to warn against) |
| Marker word / yes word | Owner-facing | Secondary reinforcer (first mention without glossary) |
| Reward / treat | Generic | Bribe (except ironic, sparingly) |
| Practise | Verb | Practice (verb) |
| Behaviour | UK spelling | Behavior |
| Settle | Invited calm | “Calm down” as command storm |
| Recall | Coming when called | “Come” only as cue example |
| Management | Prevent problem without teaching | Punishment euphemisms |
| Qualified professional | ABTC-registered or vet referral path | “Expert” without qualification |
| Worried / uncomfortable | Owner-observable | “Dominant”, “stubborn”, “guilty” |
